# Sitecatch

Collect websites into your Notion databases.

Sitecatch is an open-source (MIT), Firefox-first browser extension that saves the page you're on — screenshot, title, description, URL, and more — into the Notion database of your choice, using presets you define. It talks to the official Notion API with your own integration token. No account, no backend.
